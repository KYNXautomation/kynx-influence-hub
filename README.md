# Kynx Influence Hub

Internal desk for the creator roster. A nomination reaches the live tracker after the creator confirms, KYNX approves, and the brand approves. Stage, days late, and follow-up then come from the rate, the draft, and the post date. Campaign money is brand payment, creator cost, boosting, and VAT.

Sample records ship with the app. Names, rates, and campaign amounts are fictional stand-ins for the operating process. They are not the live sheet. Confirmation, approval, notes, and view edits stay in the browser that made them.

The published desk is https://kynxautomation.github.io/kynx-influence-hub/

```bash
npm ci
npm run dev
```

Open http://localhost:3000/kynx-influence-hub/
